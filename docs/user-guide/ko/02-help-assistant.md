# 도움말 도우미

도움말 도우미는 이 사용자 가이드만 바탕으로 앱 사용법에 관한 질문에 답해요.

## 질문하기

1. 오른쪽 아래의 **도움말**을 누르세요.
2. 질문을 입력하고 **Enter**를 누르거나 추천 질문을 누르세요. 줄을 바꾸려면 **Shift+Enter**를 누르세요.
3. 짧은 답변을 읽고, 출처 링크를 누르면 가이드의 해당 섹션 전체가 열려요.

질문은 1000자까지 쓸 수 있어요. 이어서 질문하면 바로 앞의 질문을 함께 고려하고, 도우미는 고른 표시 언어로 답해요.
**생성 중지**를 누르면 질문을 취소할 수 있어요.

## 답을 찾지 못할 때

사용자 가이드에 없는 내용이면 도우미는 추측하지 않고 찾지 못했다고 답해요. 다른 말로 물어보거나 사용자 가이드 메뉴를 살펴보세요.

도우미는 이 앱의 사용법만 알려 주고, 일반적인 질문에는 답하지 않아요.

## 문제가 생겼을 때

도우미를 쓸 수 없으면 오류 메시지와 **다시 시도** 버튼이 표시돼요. 질문은 대화에 남아 있어서 다시 시도할 수 있어요.
