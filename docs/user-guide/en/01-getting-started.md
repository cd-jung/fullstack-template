# Getting Started

This guide explains how to use the app. Open it any time from **User Guide** in the left menu.

## Finding your way around

The left menu has four sections:

- **Home**: the main feature of the app.
- **User Guide**: these pages.
- **Logs & Monitoring**: request logs and service health.
- **Coverage**: how much of the app is covered by automated tests, shown inside the app.

Logs & Monitoring and Coverage are on a separate **admin site** for administrators. Opening them from the menu takes you there, and you sign in with an approved email address (a one-time code is sent to it).

On a small screen, open the menu with the menu button in the top-left corner.

## Choosing your language

The app is available in English, Spanish (Español), French (Français) and Korean (한국어). Choose a language
from **Display language** in the top-right corner. Menus, pages, this User Guide and the Help assistant
switch to that language, and the app remembers your choice on this device.

## Getting help

Click the **Help** button in the bottom-right corner to ask a question about using the app.
The assistant answers from this User Guide only and links to the page it used.
