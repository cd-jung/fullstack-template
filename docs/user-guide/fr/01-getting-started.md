# Bien démarrer

Ce guide explique comment utiliser l'application. Ouvrez-le à tout moment depuis **Guide de l'utilisateur** dans le menu de gauche.

## Se repérer

Le menu de gauche comporte quatre sections :

- **Accueil** : la fonctionnalité principale de l'application.
- **Guide de l'utilisateur** : ces pages.
- **Journaux et surveillance** : journaux des requêtes et état du service.
- **Couverture** : la part de l'application vérifiée par des tests automatiques, affichée dans l'application.

Sur un petit écran, ouvrez le menu avec le bouton de menu en haut à gauche.

## Choisir la langue

L'application est disponible en anglais (English), espagnol (Español), français et coréen (한국어). Choisissez une
langue dans **Langue d'affichage**, en haut à droite. Les menus, les pages, ce Guide de l'utilisateur et l'assistant
d'Aide passent dans cette langue, et l'application retient votre choix sur cet appareil.

## Obtenir de l'aide

Cliquez sur le bouton **Aide**, en bas à droite, pour poser une question sur l'utilisation de l'application.
L'assistant répond uniquement à partir de ce Guide de l'utilisateur et donne le lien vers la page utilisée.
