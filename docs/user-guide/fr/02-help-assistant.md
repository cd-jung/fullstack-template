# Assistant d'Aide

L'assistant d'Aide répond aux questions sur l'utilisation de l'application, uniquement à partir de ce Guide de l'utilisateur.

## Poser une question

1. Cliquez sur **Aide**, en bas à droite.
2. Saisissez votre question et appuyez sur **Entrée**, ou cliquez sur une question suggérée. Appuyez sur **Shift+Entrée** pour aller à la ligne.
3. Lisez la réponse courte, puis cliquez sur un lien de source pour ouvrir la section complète du guide.

Les questions peuvent compter jusqu'à 1000 caractères. Une question de suivi tient compte de votre question
précédente, et l'assistant répond dans votre langue d'affichage. Cliquez sur **Arrêter** pour annuler une question.

## Quand l'assistant ne peut pas répondre

Si le Guide de l'utilisateur ne couvre pas votre question, l'assistant indique qu'il n'a pas trouvé la réponse au lieu
de deviner. Essayez d'autres mots ou parcourez le menu Guide de l'utilisateur.

L'assistant explique seulement comment utiliser cette application. Il ne répond pas aux questions générales.

## En cas de problème

Si l'assistant est indisponible, un message d'erreur s'affiche avec un bouton **Réessayer**. Votre question reste dans
la conversation, vous pouvez donc réessayer.
